# Experimental Design and Reproducibility

Experimental Python library for deterministic counterbalancing and read-only SHA-256 manifests. No participant allocation or subprocess execution. Author: Mateusz Pomianek.

Python 3.11 or newer. Install locally with `python -m pip install .`; run `python -m unittest discover -s tests -v`. See [API contract](contracts/api.json) and [documentation](docs/contracts.md). No published package.

Historical migration snapshots are not installed library modules. Complete repository license review remains open.
